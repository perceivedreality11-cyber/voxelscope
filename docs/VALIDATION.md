数值测试覆盖各向异性体积与面积、物理质心、6/26 连通性、最小尺寸筛选、ROI 边界、行 / 层索引防绕回、16 位精度与字节序、剖面守恒、空结果和非法输入。

HTTP / 运维验证使用真正启动的服务实例与独立临时 SQLite 数据库，覆盖：未认证拒绝、静态白名单、Cookie 属性、CSRF 和 Origin、三角色授权、两个企业之间的项目 / 数据 / 任务 / 复核隔离、输入字节数、规范化指纹、真实后台 worker 输出、追加复核、审计链修改检测、停用撤销会话、密码更改、重启恢复、并发上传配额、任务超时、任务取消、在线快照备份恢复、登录限流和输入文件损坏检测。

浏览器验证覆盖：登录 → 创建项目 → 加载 phantom → 分析结果 → JSON / CSV / PNG 下载 → 结果复核 → 创建分析员与查看者 → 审计验证 → 390 px 手机页面无横向溢出 → 自然排序 PNG 序列导入 → 6.25% 已知孔隙率 → 含文件头的大端 uint16 RAW 导入（1000 / 1001 灰度精度用例）→ 独立查看者会话 → 退出登录。检查浏览器未捕获异常与控制台错误。

导出验证会解析下载的 JSON 并与服务端留存报告完整比对，检查合成真值、连通域数量与体素总数；CSV 的每个数值字段与 JSON 对照；PNG 检查文件签名与有效尺寸。PNG 导入使用两张不同灰度切片，直接读取服务器中的体数据确认 `slice2` 位于 `slice10` 之前。查看者验证包括读取和导出已有结果、查看复核记录、隐藏写入及管理控件，以及通过直接 HTTP 请求确认写入仍被服务端拒绝。

RAW 增强验证覆盖：三轴区域裁剪和采样、uint16 大端及文件头、体素间距更新、源参数留存、服务端元数据一致性、4 MiB 读取预算、进度与取消、非法范围和短读错误。浏览器用例对裁剪采样后的原始字节、6.25% 孔隙率与导出元数据逐项核对。

大地址用例使用逻辑大小为 8 GiB 的虚拟 File 适配器，核对超过 4 GiB 的字节位置和有界读取。这项用例验证寻址逻辑；真实原文件的读取速度应在目标浏览器、磁盘和扫描数据上测量。

并发验证采用本机回环 HTTP，8 个不同查看者会话，每个会话发起 50 次请求，同时执行已知真值的小体积分析。实测 400 请求耗时 177.30 ms，P95 延迟 8.44 ms，8 个分析结果均匹配真值。测试结果用于复现该环境的 API 行为，TLS、长时间运行和业务数据规模在部署验收中另行记录。
