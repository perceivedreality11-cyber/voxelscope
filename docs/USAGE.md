# 使用与测量定义

## 检测流程

1. 管理员创建企业账号；分析员按工件 / 批次创建项目。
2. 导入小体积 ROI，填写真实 XYZ 体素间距。数据保存为小端 uint8/uint16，导入后不可从 API 覆盖。
3. 核对切片方向、切片顺序与工件尺寸。界面三切面显示物理比例，但不会修正错误的坐标或间距。
4. 把 ROI 限定在材料内部。矩形体与沿 Z 的椭圆柱可按各轴尺寸的 0–40% 裁边，体素边界向下取整。
5. 选择阈值、暗 / 亮极性、邻域与最小体素数，提交任务。
6. 检查切片叠色、灰度分布、深度剖面与阈值敏感性；必要时用新参数再分析。
7. 复核者从历史任务打开结果，追加接受 / 退回意见。导出 JSON 及全量连通域 CSV。

管理员和分析员都能提交复核，当前允许提交者复核自己的结果，没有强制的职责分离。复核记录不会锁定后续任务或改变原始计算结果；同一任务可以追加多条意见。

## 数据协议

RAW 的线性索引为 `x + width × (y + height × z)`。XYZ 长度各为 2–2048 的整数，总量不超过 4,194,304。间距为 0.001–1,000,000 µm 的有限正数。单文件原始大小为 `offset + X × Y × Z × bits/8`，不接受尾部多余字节。

PNG/JPEG/BMP 的灰度计算为 `round(0.2126R + 0.7152G + 0.0722B)`，所有像素必须不透明。使用浏览器解码后的 RGB 值，不是原始 CT 衰减系数。JPEG 有损压缩和色彩转换会影响定量；定量推荐重建软件导出的无损 RAW。

切片文件名以英文数字自然排序，Z 方向由排序决定。不解析 DICOM 方向矩阵，不自动纠正左右镜像，不做图像配准。请先将切片命名为无歧义的连续数字序号。

存储 SHA-256 对应的是**规范化后的体素字节流**，不是原始图片压缩文件或含文件头的 RAW。每次计算前重新校验这份体数据哈希。输入间距、位深、维度、来源类型随数据集保存；结果包含输入指纹、任务 ID、请求者、算法版本与生效参数。

## 算法定义

| 输出 | 定义与边界 |
|---|---|
| 原始分割孔隙率 | ROI 内符合灰度条件的体素数 / ROI 体素数 |
| 筛选后孔隙率 | 移除小于 minSize 的三维连通域后，保留体素数 / ROI 体素数 |
| 暗孔隙 | `gray ≤ threshold`；亮孔隙为 `gray > threshold` |
| Otsu | 在 ROI 内构建 256 个线性灰度箱，最大化类间方差；uint16 仍保留原始值作最终比较，但自动阈值受分箱精度影响 |
| 连通域 | 6 邻域仅共享面；26 邻域包括边和角。全体素统计，不使用三维显示采样结果 |
| 孔隙体积 | `N × sx × sy × sz`，单位 µm³ |
| 等效直径 | `cuberoot(6V/π)`，单位 µm；不是局部最大内切球直径 |
| 质心 | 体素中心的平均物理位置；第一个体素中心在 `(0.5sx,0.5sy,0.5sz)` |
| 体素面面积 | 暴露体素面的物理面积之和，包括 ROI 截断面；不是光滑表面面积，不能直接视为精确比表面积 |
| ROI 边界接触 | 连通域任一体素有面邻居落在 ROI 外，则记为接触。包含采样截断，不等同开孔率或真实材料表面连通性 |
| Z 剖面 | 每层保留孔隙体素 / 该层 ROI 体素。无 ROI 的层在 JSON 中为 null，界面折线以 0 展示 |
| 阈值敏感性 | 生效阈值上下各取 2 点，步长为 ROI 灰度范围 2.5%，最小 1；重新计算未做尺寸筛选的孔隙率，不是置信区间 |
| 三维点云 | 暴露孔隙体素中心的确定性均匀子采样，最多 100,000 点；颜色反映连通域体素数的对数大小，不是应力或概率 |

Otsu 对均匀灰度或缺少双峰分布的数据没有可靠的相分离意义。极高或极低的孔隙率需要回看切片。系统没有训练模型，也不自动识别纤维束、裂纹或真实材料轮廓。

企业内全体成员共享项目。账号停用立即撤销会话；同一账号再次登录会撤销前一次会话，绝对有效期为 8 小时。密码更改撤销该账号全部会话。

## 导出

JSON 包含全量组件、剖面、直方图、敏感性、生效参数、输入元数据与 provenance。CSV 包含全量保留连通域；表格界面只展示体积最大的前 100 个。三维截图仅含可视化画面和任务标识，不替代测量报告。输出没有 PDF 证书或法规签名。
