# 大文件、区域导入与采样

## RAW 读取方式

在浏览器选择 RAW 原文件后，填写完整的 XYZ 尺寸、无符号 8/16 位、字节序、文件头偏移和体素间距。平台根据文件大小校验输入，通过 `File.slice` 按区域读取；单次原文件读取不超过 **4 MiB**。服务器接收选定的分析网格，而原文件保留在用户本地。

在「RAW 区域与降采样」中设置：

| 参数 | 定义 |
|---|---|
| 区域起点 XYZ | 从 0 开始的原文件体素坐标 |
| 区域尺寸 XYZ | 沿三轴读取的范围；0 表示该轴剩余范围 |
| 采样步长 XYZ | 1 保持该轴原分辨率；2 表示每 2 个体素读取一个 |
| 输出尺寸 | `ceil(区域尺寸 / 采样步长)`，三轴分别计算 |
| 输出间距 | `原始体素间距 × 采样步长`，三轴分别计算 |

读取进度按输出体素计数，并显示已读原文件字节量。可以取消读取并调整参数后重新提交。相邻行会在读取预算内合并；大间隔采样避免为合并请求而读取过多空隙。

## 16 GiB 原文件示例

假设原始 RAW 为 `2048 × 2048 × 2048`、uint16、无文件头，大小为 16 GiB，间距 `5 × 5 × 5 µm`：

| 目的 | 区域起点 | 区域尺寸 | 步长 | 输出网格 | 输出间距 |
|---|---|---|---|---|---|
| 全范围粗采样浏览 | 0 / 0 / 0 | 0 / 0 / 0 | 16 / 16 / 16 | 128 × 128 × 128 | 80 / 80 / 80 µm |
| 指定区域原分辨率分析 | 512 / 512 / 512 | 128 / 128 / 128 | 1 / 1 / 1 | 128 × 128 × 128 | 5 / 5 / 5 µm |

两种配置生成的 uint16 网格均为 4 MiB。原文件总大小与分析网格大小是两个独立参数。此表为读取计划示例；跨 GiB 字节寻址的回归使用虚拟文件适配器，实测范围见 [验证记录](VALIDATION.md)。

## 分析网格预算与测量约定

- 每次分析网格最多 **4,194,304 体素**，每轴为 2–2048。原文件每轴可为 2–1,000,000，原文件字节地址需要满足 JavaScript 安全整数范围。
- RAW 文件长度须严格等于 `文件头偏移 + X × Y × Z × 位深 / 8`。读取器保留 unsigned uint16 数值，服务器采用小端格式存储选定网格。
- 降采样使用按步长选取体素的规则，不做均值或抗混叠滤波。较小孔隙可能被跳过；精细孔隙定量应选取原分辨率区域，并核对阈值与参考测量。
- 测量坐标基于导入后的分析网格。JSON 的 `volume.source.rawImport` 保留原始尺寸、间距、偏移、区域和步长，可据此关联原文件坐标。
- SHA-256 对服务端实际保存的分析网格计算，不代表未上传的原始整文件。采样元数据由客户端提交，服务端校验其与输出尺寸、位深和间距的一致性。
- 实际内存包括分析网格、标签、ROI、可视化和浏览器缓冲区；4 MiB 为单次原文件读取上限，不是整个程序的总内存上限。

## 切片序列与其他格式

PNG/JPEG/BMP 序列按文件名自然排序，要求尺寸相同、至少两张、无透明像素，输出为 uint8 灰度。原生 16 位定量使用 RAW。TIFF/DICOM 可在重建软件导出上述格式后导入；有符号或浮点数据先按实际重建标定转换为无符号格式，并记录转换规则。
